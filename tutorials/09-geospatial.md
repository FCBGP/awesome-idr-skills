# Tutorial — Geospatial Science (2 skills)

This category covers remote sensing/GIS/spatial analysis with a comprehensive geospatial skill, and vector geospatial data with a Python library. Use these for Earth-observation, mapping, and spatial-data work.

---

## 1. `geomaster`

**What it does.** Comprehensive geospatial science skill covering remote sensing, GIS, spatial analysis, ML for Earth observation, and 30+ scientific domains — satellite imagery processing (Sentinel, Landsat, MODIS, SAR, hyperspectral), vector/raster operations, spatial statistics, point cloud processing, network analysis, cloud-native workflows (STAC, COG, Planetary Computer), and 8 programming languages (Python, R, Julia, JavaScript, C++, Java, Go, Rust) with 500+ code examples.

**Use it when** you need remote sensing workflows, GIS analysis, spatial ML, Earth-observation data processing, terrain analysis, hydrological modeling, marine spatial analysis, atmospheric science, or any geospatial computation.

**Example scenario.** An Earth-observation researcher wants to process satellite imagery:
> "Use **geomaster** to process **Sentinel-2 imagery** for land-cover classification — atmospheric correction, vegetation indices, and a spatial ML model."

---

## 2. `geopandas`

**What it does.** Python library for **vector geospatial data** — shapefiles, GeoJSON, GeoPackage — spatial analysis, geometric operations, coordinate transformations, spatial joins, overlays, choropleth mapping, and PostGIS databases.

**Use it when** you work with geographic vector data — buffer analysis, spatial joins, dissolving boundaries, clipping, calculating areas/distances, reprojecting, creating maps, or converting spatial formats.

**Example scenario.** A city planner wants to analyze zoning against population:
> "Use **geopandas** to **spatially join** my zoning polygons with population points — buffer analysis, clipping, and a choropleth map of density."
